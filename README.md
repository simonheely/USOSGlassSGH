# USOS Glass SGH

Natywny prototyp SwiftUI z elementami Liquid Glass, iOS 26+.

**Dane demonstracyjne. Brak połączenia z USOS SGH.** Nie jest to oficjalna aplikacja uczelni. Kompilacja i instalacja wymagają weryfikacji na urządzeniu.

## Plik instalacyjny

1. Otwórz Actions → Build downloadable iPhone IPA.
2. Poczekaj na zielony wynik uruchomienia albo wybierz Run workflow.
3. Pobierz artifact USOSGlassSGH-iPhone-IPA i rozpakuj ZIP.
4. Plik USOSGlassSGH-unsigned.ipa zainstaluj przez AltStore Classic.

## Windows i bezpłatne konto Apple

Zainstaluj AltServer oraz zależności według https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows . Podłącz iPhone kablem, zaufaj komputerowi, włącz synchronizację Wi-Fi i wybierz Install AltStore w AltServer. Na telefonie zaufaj profilowi i włącz Tryb dewelopera. W AltStore → My Apps → + wybierz IPA. Apple ID wpisuj w AltServer/AltStore, nie w repozytorium ani czacie.

Bezpłatny podpis wygasa po 7 dniach; odnawiaj aplikację z działającym AltServerem. GitHub buduje na hostowanym Macu; Windows służy do instalacji. Niepodpisany IPA nie instaluje się przez samo otwarcie w Safari.
